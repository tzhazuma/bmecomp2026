# 文献调研报告

## 1. 研究背景

### 1.1 注意缺陷多动障碍（ADHD）

注意缺陷多动障碍（ADHD）是一种常见的儿童神经发育障碍，主要表现为注意力不集中、多动和冲动行为。全球约有5-7%的儿童受此影响。

### 1.2 自闭症谱系障碍（ASD）

自闭症谱系障碍（ASD）是一组复杂的神经发育障碍，主要特征为社交沟通障碍和重复刻板行为。ASD儿童常伴随注意力问题。

### 1.3 传统训练方法的局限性

传统专注力训练方法存在以下问题：
- 趣味性不足，儿童依从性差
- 反馈不直观，难以量化训练效果
- 训练场景单一，泛化能力弱
- 需要专业人员指导，成本高

## 2. 脑机接口（BCI）技术

### 2.1 BCI概述

脑机接口（Brain-Computer Interface, BCI）是一种直接连接大脑和外部设备的技术，通过检测和分析脑电信号，实现人机交互。

### 2.2 BCI在注意力训练中的应用

#### 文献1：Home-based brain–computer interface attention training program for attention deficit hyperactivity disorder: A feasibility trial

**作者**: Lim CG, Soh CP, Lim SS, Fung DSS, Guan C, et al.

**期刊**: Child and Adolescent Mental Health, 2023

**摘要**: 本研究评估了基于BCI的家庭注意力训练项目对ADHD儿童的可行性。结果表明，BCI训练可以显著改善ADHD儿童的注意力症状，且具有良好的依从性。

**关键发现**:
- BCI训练可以改善ADHD儿童的注意力
- 家庭环境下的BCI训练具有可行性
- 儿童对BCI训练的依从性良好

## 6. 儿童使用VR的注意事项

### 6.1 年龄限制

- Meta官方建议13岁以上使用VR设备
- 研究表明，儿童使用VR需要注意时间和内容

### 6.2 健康风险

- VR可能导致眩晕和恶心
- 长时间使用可能影响视力
- 需要适当休息和监督

### 6.3 安全建议

- 每次使用时间不超过30分钟
- 需要家长在旁监督
- 选择适合儿童的内容
- 注意保护视力

## 7. 研究趋势

### 7.1 技术趋势

1. **单通道BCI设备**: 更便携、易用，适合家庭和学校使用
2. **VR技术**: 更沉浸、更自然，提供更好的训练体验
3. **多模态融合**: 结合多种信号，提高训练效果
4. **游戏化设计**: 提高儿童的参与度和依从性

### 7.2 应用趋势

1. **家庭训练**: BCI-VR系统适合家庭使用
2. **学校教育**: 可以作为辅助教学工具
3. **临床康复**: 可以作为康复训练的补充
4. **远程医疗**: 可以支持远程训练和评估

## 8. 研究空白与机会

### 8.1 现有研究的不足

1. **样本量小**: 大多数研究样本量有限
2. **长期效果**: 缺乏长期随访研究
3. **个体差异**: 缺乏个性化训练方案
4. **成本效益**: 缺乏成本效益分析

### 8.2 本项目的创新点

1. **多模态融合**: 结合EEG和IMU，提供更全面的控制
2. **低成本方案**: 使用单通道BCI设备，降低成本
3. **游戏化设计**: 提供沉浸式训练体验
4. **家庭适用**: 系统适合家庭使用

2. **可行性**: 单通道BCI设备适合家庭和学校使用
3. **趣味性**: 游戏化训练可以提高儿童的依从性
