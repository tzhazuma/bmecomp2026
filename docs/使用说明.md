# 使用说明

## 一、环境搭建

### 1.1 安装 Python 依赖

```bash
# 克隆仓库
git clone git@github.com:tzhazuma/bmecomp2026.git
cd bmecomp2026

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install --upgrade pip
pip install -r requirements.txt
```

### 1.2 安装 Unity

1. 从 Unity Hub 安装 **Unity 2021.3 LTS** 或更高版本
2. 在 Unity Hub 中点击 **Open**，选择 `src/unity/` 目录
3. Unity 会自动导入项目，安装必要 Packages（提示时安装）：
   - **XR Interaction Toolkit** (2.5.4+)
   - **XR Plugin Management** (4.4.0+)
   - **Oculus XR Plugin** (4.2.0+) —— 如使用 Quest
   - **OpenXR Plugin** —— 跨平台支持
   - **TextMeshPro** (3.0.6+)
   - **Post Processing** (3.2.0+)

### 1.3 配置 VR 头显（若使用）

1. 在 Unity 中打开 **Edit → Project Settings → XR Plug-in Management**
2. 启用 **Oculus** 或 **OpenXR**
3. 如使用 Quest 3，确保已安装 Meta Quest Developer Hub 并激活开发者模式

## 二、运行系统

### 2.1 无硬件模式（Mock 模式 - 推荐用于开发测试）

**此模式无需连接任何脑电设备或 VR 头显。**

```bash
# 终端 1：启动 Python BCI 中间件
cd bmecomp2026
source venv/bin/activate
python src/python/main.py
```

输出示例：
```
╔══════════════════════════════════════════╗
║     BCI-VR 注意力训练系统                  ║
╚══════════════════════════════════════════╝

数据源模式: MOCK
Unity服务器: 0.0.0.0:5555
信号处理: 窗口=7, alpha=0.7, 死区=5.0
--------------------------------------------------
✓ 平台连接: 已建立
系统运行中... 按 Ctrl+C 停止

[14:30:25] ✓ 专注力: 62.3 Yaw: +1.2 Pitch: -0.8 包: 127 运行: 2s
```

2. 在 Unity 中打开 `Assets/Scenes/MainMenu.unity`，点击 **Play**
3. BCIManager 自动连接 127.0.0.1:5555，数据确认后即可进入游戏

### 2.2 连接 HybridBCI 平台（需硬件）

```bash
# 1）确保已佩戴头环，HybridBCI 平台已登录并连接头环
# 2）确保平台的多模态综合控制模块已启动

# 3）启动 Python 中间件（TCP 模式）
python src/python/main.py --mode tcp

# 或者修改 config.yaml 中的 mode 字段为 "tcp"
```

### 2.3 连接真机 VR

1. 将 Quest 3 通过 **Link 线** 连接至 PC（或使用 AirLink）
2. 确保 Unity 项目已正确配置 Oculus XR Plugin
3. 在 Unity 中 Build & Run，或导出 APK 安装至 Quest
4. PC 端运行 Python 中间件，Quest 内的游戏会自动连接

## 三、游戏操作

### 3.1 控制方式

| 控制 | 方式 |
|------|------|
| 飞船速度 | 专注力越高速度越快（无需手动操作） |
| 水平移动 | 头动信号 Yaw（左右摇头） |
| 垂直移动 | 头动信号 Pitch（上下点头） |
| VR 视角 | Quest 原生 6DoF 头部追踪 |
| 暂停 | 按 ESC 键 或 Quest 菜单键 |

### 3.2 游戏流程

1. **主菜单** → 选择关卡（需解锁）
2. **专注力校准**（可选） → 放松 10 秒建立基线
3. **游戏开始** → VR 飞船自动前进
4. **训练结束** → 显示训练报告（专注力曲线、分数、星级）

### 3.3 评分规则

| 星级 | 条件 |
|------|------|
| ⭐⭐⭐ | 平均专注力 ≥ 75 且 得分 ≥ 基础分 × 2 |
| ⭐⭐ | 平均专注力 ≥ 60 或 得分 ≥ 基础分 |
| ⭐ | 平均专注力 ≥ 40 |

## 四、配置说明

### 4.1 `config.yaml` 完整配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `data_source.mode` | `mock` | 数据源模式：`mock`(模拟) / `local`(QLocalSocket) / `tcp`(TCP) |
| `mock.attention_min` | 30.0 | 模拟专注力最小值 |
| `mock.attention_max` | 90.0 | 模拟专注力最大值 |
| `mock.attention_freq` | 0.1 | 模拟专注力波动频率 (Hz) |
| `mock.imu_noise` | 3.0 | IMU 模拟噪声角度 |
| `mock.update_rate` | 50 | 数据更新频率 (Hz) |
| `unity_server.port` | 5555 | 转发至 Unity 的端口 |
| `signal_processing.window_size` | 7 | 滑动平均滤波窗口 |
| `signal_processing.alpha` | 0.7 | 指数平滑系数 |
| `signal_processing.imu_deadzone` | 5.0 | 头动死区角度 |
| `game.session_duration_sec` | 180 | 单次训练时长 (秒) |
| `game.focus_threshold` | 70 | 专注力阈值 |
| `game.combo_threshold_sec` | 10 | 连击触发时长 |

## 五、故障排除

### 5.1 Python 中间件

| 问题 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: No module named 'yaml'` | 缺少 PyYAML | `pip install pyyaml` |
| 连接被拒绝 | Unity 未启动 或端口被占用 | 检查 Unity 端 BCIManager 是否在运行 |
| 专注力一直为 0 | Mock 模式未生效 | 检查 config.yaml 中 `mode: mock` |
| 高延迟 | Windows 防火墙阻止 | 添加防火墙规则放行 5555 端口 |

### 5.2 Unity

| 问题 | 原因 | 解决 |
|------|------|------|
| XR 设备不显示 | XR Plugin 未配置 | Edit → Project Settings → XR Plug-in Management |
| Post Processing 无效果 | Volume 未添加 | 在场景中创建 Post-process Volume |
| TextMeshPro 报错 | TMP Essentials 未导入 | Window → TextMeshPro → Import TMP Essentials |

## 六、常见问题

**Q: 没有 HNNK 头环能开发吗？**  
A: 可以。使用 Mock 模式即可在无硬件情况下完成所有游戏逻辑开发。

**Q: VR 头显是必需的吗？**  
A: 不是。可以在 Unity Editor 中直接运行（非 VR 模式），查看 UI 反馈和数据显示。

**Q: 儿童使用 VR 安全吗？**  
A: Meta 官方建议 13 岁以上，但研究表明在家长监督下、单次不超过 30 分钟是安全的。建议每次训练 3-5 分钟。

**Q: 游戏如何记录训练数据？**  
A: Python 中间件自动记录全部原始数据（JSON Lines），Unity 端记录训练摘要（JSON），均保存在 `session_data/` 目录。
